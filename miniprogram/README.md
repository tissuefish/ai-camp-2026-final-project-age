# AI 年龄估计 · 微信小程序（展示用）

这个小程序只是**前端界面**，真正的年龄预测模型跑在你电脑上（`app.py` + 公网隧道）。
小程序通过公网链接调用电脑端的预测接口。

## 运行前提（先做这个）

1. 电脑上启动网页服务：双击 `..\启动演示.bat` 或运行 `python app.py`
2. 电脑上启动公网隧道：双击 `..\公网展示.bat`（或在 cloudflared 窗口里确认分享链接）
3. 复制隧道窗口里的公网地址（形如 `https://xxxx.trycloudflare.com`）

## 打开小程序

1. 打开 **微信开发者工具**
2. 点"导入项目"，目录选择本文件夹（`miniprogram`）
3. AppID：选 **测试号**（游客模式），或填你自己的小程序 AppID
4. 关键设置：在开发者工具右上角"详情 → 本地设置"里，勾选 **"不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书"**（因为这是临时公网链接，不在微信合法域名白名单里）
5. 点击编译，即可在模拟器里使用：选照片 → 开始估计

## 换链接时

公网隧道链接每次重启都会变。变了之后，把 `pages/index/index.js` 最上面的 `API_URL` 改成新链接即可。

## 说明

- 小程序只是前端展示，方便发给大家看；正式课程提交仍是本地可复现的 Python 项目（见上级目录 README）。
- 想在手机真机上用：在开发者工具"预览"生成二维码，手机扫码即可（需要手机和电脑网络通畅）。
